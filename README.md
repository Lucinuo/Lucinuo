# Lucinuo

**Research. Build. Grow.**

Lucinuo is the independent practice of Lucille Huang—bringing together biological research, useful digital tools, and systems for clearer thinking.

## Research

Biological questions, evidence architecture, scientific visualization, and careful claims.

## Build

Digital tools, AI-assisted workflows, websites, data visualization, and practical knowledge systems.

## Grow

Reflection, learning methods, and systems that turn understanding into deliberate next steps.

## Bearing

**See clearly. Move deliberately.**

Bearing is a personal system for reflection, direction, and action—and one of Lucinuo's core products.
